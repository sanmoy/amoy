# Amoy

A small static site of poems and pictures for Amoy, to be read on an old Kindle e-paper browser.

Pages are plain HTML and CSS. Bengali is set in a self-hosted copy of Noto Sans Bengali. Open `index.html`, or visit [https://nascentsoftware.com/amoy/](https://nascentsoftware.com/amoy/).

`AGENTS.md` describes the constraints, the layout of the site, and how to add a poem or a section.
