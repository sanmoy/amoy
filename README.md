# Amoy

A small static site of poems, figures, and songs for Amoy, to be read on an old Kindle e-paper browser.

Pages are plain HTML and CSS. Bengali is pre-shaped into a small self-hosted font so the old Kindle does not have to shape it. Figures are solid black shapes on white. Open `index.html`, or visit [https://nascentsoftware.com/amoy/](https://nascentsoftware.com/amoy/).

`AGENTS.md` describes the constraints, the layout of the site, and how to add a poem, a figure, or a song.
